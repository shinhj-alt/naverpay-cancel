# 네이버페이 취소 완료처리 자동화

취소요청 목록에서 날짜 조건에 맞는 건을 자동으로 "취소 완료처리" 합니다.  
로그인은 사용자가 직접 진행합니다.

---

## 설치 (최초 1회)

### 1. Node.js 설치
https://nodejs.org/ko → LTS 버전 다운로드 후 설치

### 2. 의존성 설치
압축 푼 폴더에서 아래 명령어 실행:

```
npm install
```

### 3. 브라우저 설치 (시스템 Chrome이 없는 경우에만)
```
npm run install-browser
```
> 이미 Chrome이 설치되어 있으면 이 단계는 생략 가능합니다.

---

## 실행

```
npm start
```

콘솔에 뜨는 주소를 브라우저로 열기:
```
http://localhost:3000
```

---

## 사용 방법

1. **실행** 버튼을 누르면 Chrome 창이 별도로 열립니다.
2. 열린 Chrome에서 **네이버페이 판매자센터에 직접 로그인**합니다. (2차 인증 포함, 최대 5분)
3. 로그인 완료 후 자동으로 취소요청 목록을 처리합니다.
4. 로그인 세션은 저장되므로 **다음 실행부터는 로그인 생략**됩니다.

### 날짜 필터
- 결제일 / 취소요청일의 시작~끝 범위를 설정할 수 있습니다.
- **비워두면 해당 조건은 적용되지 않습니다** (전체 처리).
- 시작만 또는 끝만 입력해도 됩니다.

### DRY RUN
- 체크하면 실제 처리 없이 몇 건이 매칭되는지만 확인합니다.
- 처음 사용할 때 먼저 DRY RUN으로 확인 후 실제 실행을 권장합니다.

---

## 주의사항

- 이 도구는 **본인 PC에서만 동작**합니다. (브라우저 자동화가 로컬에서 실행됨)
- 한 번에 1개 작업만 실행됩니다. 실행 중에는 실행 버튼이 비활성화됩니다.
- 로그인 세션(`.browser-profile/` 폴더)은 다른 사람과 공유하지 마세요.
