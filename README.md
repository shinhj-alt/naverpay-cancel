# 네이버페이 취소요청 자동처리

웹 UI로 결제일 / 취소요청일 범위를 설정하고, 그 조건에 맞는 건만 자동으로 "취소 완료처리"합니다.
**로그인은 사용자가 직접** 진행합니다.

## 사전 준비 (어느 PC든 동일)

1. [Node.js LTS](https://nodejs.org/ko) 설치
2. 이 폴더에서 (최초 1회):

```bash
npm install
npm run install-browser
```

Windows / macOS / Linux 모두 동일하게 동작합니다.

## 실행

```bash
npm start
```

콘솔에 표시되는 주소를 브라우저로 열기:

```
http://localhost:3000
```

UI에서:
1. 결제일 / 취소요청일 시작·종료 시각 입력 (비우면 그 조건은 전체)
2. `DRY RUN` 체크 상태에서 먼저 실행 → 매칭 건수 확인
3. 문제 없으면 `DRY RUN` 해제 후 실행 → 실제 처리

자동화 브라우저가 별도 창으로 열립니다. 거기서 직접 로그인하면(2차 인증 포함, 최대 5분 대기) 그 뒤로는 자동으로 처리됩니다.

## 동작 흐름

1. UI에서 폼 제출 → 서버가 자동화 시작
2. Playwright가 Chromium 창을 열고 네이버페이 admin 페이지로 이동
3. 사용자가 직접 로그인
4. 로그인 감지 → 취소요청 목록 페이지 이동
5. 헤더에서 `결제일`, `취소요청일` 컬럼 자동 탐지
6. 조건에 맞는 행을 1건씩 선택 → "취소 완료처리" 클릭
7. 확인 팝업 2개 자동 수락 (네이티브 dialog + HTML 모달 모두 대응)
8. 목록 갱신 대기 → 다음 매칭 행 처리 → 반복
9. 처리 로그가 UI에 실시간으로 표시됨

## 컬럼/버튼명이 다를 때

`index.js` 상단 `CFG` 블록 수정:

```js
const CFG = {
  payDateHeader: '결제일',
  requestDateHeader: '취소요청일',
  completeButtonText: '취소 완료처리',
};
```

실행 직후 로그에 `[테이블 헤더] [...]` 가 출력되므로 그 값을 보고 수정하면 됩니다.

## 주의

- 네이버페이 약관상 비정상적 자동화 접근이 제한될 수 있습니다.
- 서버는 `127.0.0.1` 만 바인딩하므로 같은 PC에서만 접근 가능합니다.
- 한 번에 1개의 작업만 처리합니다 (동시 실행 불가).
