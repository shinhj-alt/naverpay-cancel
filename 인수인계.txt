■ 이게 뭐하는 프로그램인가요?

네이버페이 결제센터(admin.pay.naver.com)의 "취소요청" 건들을
자동으로 "취소 완료처리" 해주는 프로그램입니다.
건별로 일일이 클릭할 필요 없이, 실행 한 번으로 전부 처리됩니다.


■ 설치 (최초 1회)

1. 이 압축파일을 원하는 위치에 풀기 (예: 바탕화면)
   ※ 반드시 압축을 푼 다음에 실행하세요. ZIP 안에서 바로 실행하면 안 됩니다.
2. 끝. 별도 설치 프로그램 없음 (node.exe가 폴더에 포함되어 있음)


■ 사용 방법

1. 폴더 안의  start.bat  더블클릭
   - 검은 창이 뜨고, 잠시 후 브라우저에 관리 화면이 자동으로 열립니다
   - 최초 1회만 브라우저 구성요소를 자동 설치합니다 (1~2분 소요)
   - 검은 창은 닫지 말고 그대로 두세요 (닫으면 프로그램 종료됨)

2. 관리 화면에서:
   - [오늘 취소요청 마감 시각] : 시/분 숫자 입력 (24시간 표기)
     예) 14시 30분 → "오늘 14:30 이전에 들어온 취소요청만" 처리
     비워두면 → 전체 취소요청 처리
   - [DRY RUN 모드] 체크 : 실제 처리 없이 "몇 건이 대상인지"만 확인
     ★ 처음 쓸 때는 꼭 DRY RUN으로 먼저 확인하세요
   - [실행] 버튼 클릭

3. Chrome 창이 열리면서 네이버 로그인 화면이 뜹니다
   - 본인의 네이버페이 관리자 계정으로 직접 로그인하세요 (최대 5분 대기)
   - 한 번 로그인하면 세션이 저장되어 다음부터는 자동 로그인됩니다

4. 로그인 후 자동으로 처리가 진행됩니다
   - 관리 화면의 로그 패널에서 진행 상황 실시간 확인 가능
   - 처리 끝나면 브라우저는 직접 닫으면 됩니다 (10분 후 자동 정리)


■ 주의사항

★ 실제 처리는 되돌릴 수 없습니다. 반드시 DRY RUN으로 건수를 먼저
  확인한 뒤 실제 실행하세요.
★ 로그인 세션은 .browser-profile 폴더에 저장됩니다.
  - 다른 사람에게 이 폴더를 통째로 복사해서 주면 안 됩니다 (계정 세션 포함)
  - 로그아웃하려면: 관리 화면 우측 상단 [세션 삭제] 버튼
★ 실행 중 네이버 화면이 바뀌었는데 동작이 이상하면
  네이버 결제센터 UI가 개편됐을 가능성이 큽니다 (아래 문제 해결 참고)


■ 문제 해결

▷ "연결할 수 없음" / 화면이 안 열림
   → 검은 창(start.bat)이 꺼져있는 것. start.bat 다시 실행

▷ 실행했는데 "0건" 으로 나옴 (실제로는 건이 있는데)
   → 네이버 결제센터 화면이 개편되어 표(테이블) 구조가 바뀐 것일 수 있음.
     개발 지식이 있는 사람에게 index.js 의 getDataRows 부분 수정 요청

▷ 로그인 창이 안 뜨거나 바로 꺼짐
   → 검은 창을 닫고 start.bat 재실행. 그래도 안 되면
     .browser-profile 폴더를 삭제 후 재시도 (다시 로그인 필요)

▷ 처리 도중 "세션 만료" 오류
   → 브라우저에서 네이버에 다시 로그인한 뒤 [실행] 다시 클릭


■ 파일 구성

  start.bat        : 실행 파일 (이것만 더블클릭하면 됨)
  index.js         : 프로그램 본체 (서버 + 자동화 로직)
  public\index.html: 관리 화면 UI
  node.exe         : 실행 엔진 (Node.js, 설치 불필요하게 동봉)
  node_modules\    : 프로그램 부품 (건드리지 말 것)
  install-browser.js: 최초 브라우저 설치 스크립트 (자동 실행됨)
